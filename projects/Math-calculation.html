Overview

Math-Calculation is a collection of mathematical algorithms implemented in Python or R. The repository currently includes a linear algebra program that solves systems of equations using Gaussian elimination.

Context

This project is intended for study, practice and reference. The elimination program provides a practical way to follow the row operations used to solve a system of linear equations.

Problem

Solving a system by hand involves a sequence of row operations that can be difficult to track. This program accepts the system's coefficients and right-hand-side values, then displays the augmented matrix as the calculation progresses.

My contribution

I implemented an interactive command-line program that reads the system size, validates the coefficient rows and right-hand-side values, and prints the resulting solution when the system has a unique solution.

Technical approach

The implementation uses partial pivoting to select the largest available pivot in each column. It then normalizes pivot rows and eliminates the corresponding values from the other rows, displaying the augmented matrix after each operation. A numerical tolerance is used when checking for near-zero pivots and values.

Challenges

The program needs to handle invalid user input and account for floating-point precision. It also detects when a pivot is too close to zero to proceed with a unique solution.

Result

The current implementation solves square systems with a unique solution and prints both the row operations and the final values of the unknowns. Systems without a unique solution are reported as an error.

What I learned

This project demonstrates how row operations, partial pivoting and floating-point tolerances can be translated into a step-by-step algorithm, as well as how input validation supports a more reliable command-line tool.
