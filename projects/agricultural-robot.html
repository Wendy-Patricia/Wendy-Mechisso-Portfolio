Agricultural Robot

A robotics project exploring camera-based crop-line following, motor control and the foundations for an agricultural monitoring system.

Robotics / Computer Vision

Overview

The project aims to build a robot that follows a crop line, identifies threats along its route and reports useful information to a PC interface. The current code focuses on camera-based line detection and navigation.

Context

Developed as a robotics project, the system combines a mobile robot, visual processing and a planned user interface. The exact crop, threat types and elimination method still need to be defined with the project supervisors.

Problem

A robot operating along a crop row needs to estimate where the line is in the camera image and adjust its movement accordingly. It also needs a safe response when the line is not detected.

My contribution

The current implementation includes Python modules for camera capture, line detection, navigation decisions and motor control. The line detector supports predefined colors and configurable HSV ranges. Update this section to describe your individual contribution and teamwork accurately.

Technical approach

OpenCV converts the camera image to HSV and creates a mask for the selected line color. The detector estimates the line's horizontal position and returns a normalized error. Navigation uses that error to request a turn, move forward or stop. Motor control uses PWM through Raspberry Pi GPIO, with reusable channels and a simulated motor implementation for tests.

Challenges

The project addresses color-based detection, separating navigation decisions from hardware control, and making the code testable without a camera or physical motors. Reliable HSV thresholds still need to be tuned for the actual camera, lighting and track.

Result

Automated tests cover synthetic line images, position estimates, color filtering, navigation commands and simulated PWM behavior. Testing with the physical robot and camera remains a separate step. Threat recognition, the elimination mechanism and PC communication are project goals, not verified features of the current implementation.

What I learned

This project provided practical experience with image processing, HSV color ranges, modular Python design, hardware abstraction and testing robotics behavior without activating physical hardware.
