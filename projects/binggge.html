Entertainment / Web Application

Binggge

A web application for discovering TV shows and building a personal watchlist, powered by TVMaze and PostgreSQL.

JavaScript Node.js Express PostgreSQL Vite

Case study

Entertainment / Web

Overview

Binggge helps users search for TV shows and save titles to a personal watchlist. The project combines a JavaScript frontend, a Node.js and Express API, PostgreSQL persistence, and show data from TVMaze.

Context

Binggge is a personal web application developed incrementally. It brings show discovery and watchlist management together in one place.

Problem

Finding a show is only part of the experience. Users also need a simple way to keep track of titles they want to watch and retrieve their list later.

My contribution

I built the web interface and connected it to the application API. The interface supports show search, paginated catalog results, user registration, and adding titles to a personal watchlist.

Technical approach

The frontend uses JavaScript and Vite. Vite proxies API requests to a Node.js and Express backend. The API searches TVMaze and uses PostgreSQL to store users and their watchlist entries.

Catalog pagination is handled in the frontend, showing six search results per page. Search starts empty and runs when the user submits a query.

Challenges

Connecting the frontend to the API required coordinating local development across separate servers. The watchlist also needs to be associated with the correct user when retrieving saved shows.

Result

The current development version supports show discovery and watchlist creation. Authentication is simplified and uses an X-User request header; it does not yet use passwords, sessions, or tokens.

What I learned

This project gave me practical experience connecting a frontend to a REST API, working with PostgreSQL, integrating an external data source, and handling user-specific data.
