Case study

Ticketing / Web

Overview

Concert Ticketing System - Encore is a web application for browsing concerts, purchasing tickets, and managing events. It combines a searchable catalogue, customer registration, and a loyalty programme offering a 10% discount.

Context

The project was developed in a team of two. Responsibilities were divided between the concert catalogue, infrastructure, and security, and the customer, loyalty, and purchasing modules. Both parts were integrated into a single application with a Java backend and a Portuguese interface.

Problem

The goal was to centralise information about artists, venues, and concerts while providing a reliable ticket purchasing process. The application needed to validate data, enforce access permissions, calculate prices, and prevent purchases exceeding venue capacity.

My contribution

My contribution focused on the concert catalogue, infrastructure, and security. I worked on modelling artists, venues, and concerts, implementing REST endpoints, and configuring role-based permissions. I also contributed to database migrations, API documentation, and catalogue tests.

Technical approach

The backend uses Java 25 and Spring Boot, with separate controller, service, and repository layers. Spring Data JPA and MySQL handle persistence, while Flyway manages versioned database migrations.

Spring Security controls access through CLIENT, PRODUCTEUR, and ADMIN roles. The API is documented with Swagger/OpenAPI, and MySQL runs through Docker Compose. The HTML, CSS, and JavaScript frontend communicates directly with the backend

Challenges

A key challenge was integrating both modules while keeping entities, API contracts, and database migrations consistent. Another was maintaining accurate ticket availability during simultaneous purchases, using database transactions and locking.

The project also required consistent validation across the application and database, alongside clear error messages in the interface.

Result

The resulting application supports concert searches, customer registration, loyalty card activation, and purchases of one to six tickets. It also includes role-protected management features and automated tests covering business rules, security, persistence, and concurrent purchases.
