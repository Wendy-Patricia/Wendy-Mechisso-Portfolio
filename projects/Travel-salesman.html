Traveling Salesman Solver

A C-based project focused on finding the shortest possible route between a set of cities using combinatorial optimization and distance analysis.

Computer Science / Algorithms

Overview

This project explores the Traveling Salesman Problem (TSP), one of the most well-known optimization challenges in computer science. The goal is to determine the shortest route that visits each city exactly once and returns to the starting point.

Context

The project was developed as part of a first-year university programming assignment in computer science. It combines algorithm design, coordinate generation, Euclidean distance calculation and brute-force optimization in a practical C implementation.

Problem

With a set of cities placed on a grid, the challenge is to compute all possible routes, evaluate their total distances and identify the optimal path. Since the number of permutations grows factorially, brute-force becomes heavy as the number of cities increases.

My contribution

I implemented the core logic for random point generation, distance matrix creation, exhaustive route checking and route visualization in the console. I also added a nearest-neighbor heuristic and a simplified electric-vehicle simulation to compare different route-planning approaches.

Technical approach

The solution generates 8 random, non-overlapping coordinates, computes the Euclidean distance between every pair of points and stores the results in a matrix. Then, it tests all possible city permutations to find the shortest tour. A second heuristic approach approximates a fast path using a nearest-neighbor strategy, while an additional module models a simplified electric trip with charging assumptions.

Challenges

One of the main challenges of the project is the factorial growth of the search space. For 8 cities, there are already 40,320 possible routes, which makes exact computation feasible but limited to small instances. The program also had to balance brute-force optimization with readable console output and visual route representation.

Result

The project successfully demonstrates how algorithmic thinking can be applied to a real optimization problem in C. It displays the generated points, the distance matrix, the optimal route, and a heuristic comparison. The project is a strong example of algorithmic problem solving and early-stage software experimentation.

What I learned

This project strengthened my understanding of algorithm complexity, optimization strategies, and practical C programming. It also showed me how important it is to choose between exact solutions and heuristic methods depending on the size of the problem.
