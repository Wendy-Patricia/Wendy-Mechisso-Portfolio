Overview

A real-time hand-tracking and finger-counting application built with Python, OpenCV, and NumPy. It processes webcam images to identify a hand silhouette, count between zero and five raised fingers, and display an estimated hand skeleton.

Context

This project explores how traditional computer vision can support gesture-based interaction. It uses image processing and geometric analysis without neural networks, pretrained models, or MediaPipe. All images are processed locally.

Problem

The main challenge was to turn a webcam image into a stable finger count. Lighting, background colours, hand size, and finger position can affect detection. The system also needed to distinguish a closed fist from an open hand and recognise a thumb extended sideways.

My contribution

I developed the processing pipeline, from webcam capture and hand segmentation to finger counting and visual feedback. I added interactive controls for adjusting detection parameters, temporal filtering to stabilise the count, and automated tests using synthetic hand silhouettes. I also organised the code into separate modules for processing, geometry, controls, and visualisation.

Technical approach

I converted each frame to HSV and applied adjustable colour thresholds to isolate the hand. Gaussian blur and morphological operations helped clean the binary mask before selecting the largest valid contour.

I estimated the palm centre and radius using a distance transform. After resampling and smoothing the contour, I detected fingertip candidates through their distance from the palm, prominence, and local curvature. Convexity defects helped locate the gaps between fingers.

To reduce flickering, I stabilised the count through a vote over the last seven frames, requiring four matching observations to validate a new count.

Challenges

The main challenges were handling changing lighting, preventing the forearm from distorting palm estimation, and recognising lateral thumbs. I addressed these through adjustable HSV controls, palm-relative geometric thresholds, and candidate filtering. I also made uncertain results expire so the application would not keep displaying an outdated count.

Result

The application supports webcam processing, silhouette analysis from image files, and visual overlays showing fingertips, finger gaps, and an estimated skeleton. The project includes 16 automated tests covering synthetic finger combinations, mirrored silhouettes, changes in scale, limited rotations, and temporal stabilisation.

Real-world accuracy has not been quantified. Performance depends on segmentation quality, visible fingers, and a palm-facing hand position.

What I learned

I learned how to combine colour segmentation, contour analysis, and temporal filtering into a complete computer vision pipeline. The project strengthened my understanding of geometric feature detection, modular Python development, and testing without physical camera hardware. It also showed me how strongly input quality affects the reliability of a vision system.
