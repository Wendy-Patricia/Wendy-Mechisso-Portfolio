Game Development / Academic Project

World of IUT

A text-based exploration game built in C, focused on player movement, interconnected locations, and dynamic memory management using custom data structures.

C Data Structures Dynamic Memory Pointers Game Logic

Case study

Game / C Project

Overview

World of IUT is a text adventure game developed in C as part of a first-year university project. The player navigates through a series of interconnected locations, moves between them, and explores the environment through a command-driven interface.

Context

This project was created during the SAE 1.01 course at IUT Saint-Dié-des-Vosges, within the BUT Informatique program. It was designed to apply fundamental programming concepts such as modular design, memory management, and structured data handling.

Problem

The goal was to create a playable game world with navigation logic, dynamic allocation, and memory cleanup while keeping the code organized across multiple modules. The project also had to model a connected map of locations and handle movement between them reliably.

My contribution

I contributed to the implementation of the core game structure, particularly the location system and the stack-based memory management. I developed the logic behind creating and destroying locations, setting exits between rooms, and managing the in-game world state.

Technical approach

The project was developed in C using a modular architecture. Each area of the game was separated into dedicated files, including location management, player movement, command processing, and resource cleanup. A custom stack structure was used to manage dynamically allocated locations and ensure controlled freeing of memory.

The game world is represented as a set of interconnected places, and movement is handled by linking exits in different directions such as north, south, east, west, up, and down. This allowed the player to explore the map through text commands while maintaining a clear state model for the game.

Challenges

One of the main challenges was managing dynamic memory safely and avoiding leaks when the game was initialized and shut down. Another important part was ensuring the location graph remained consistent and that each movement operation updated the player’s current location correctly.

Result

The project resulted in a working text-based exploration game with a structured world, navigable rooms, and a reliable memory management system. It demonstrates strong understanding of C fundamentals and data structure design in a practical, interactive application.

What I learned

This project strengthened my understanding of dynamic memory allocation, pointer usage, structured program design, and the importance of careful resource management in C. It also improved my ability to translate a game concept into a modular and maintainable software architecture.
