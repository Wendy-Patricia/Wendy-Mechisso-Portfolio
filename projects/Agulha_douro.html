Agulha d'ouro

A corporate website developed for Atelier Agulha D'Ouro, a fashion atelier specializing in haute couture, bridal gowns, and custom-made garments.

JavaScript Node.js Express PostgreSQL Vite

Case study

Fashion / Web

Overview

The website introduces Agulha D'ouro Atelier and its bespoke creations. It brings together information about the atelier, its services, its process, and how to get in touch.

Context

Agulha D'ouro Atelier creates bespoke clothing, including wedding dresses, formalwear, garments made with capulana and linen, and professional uniforms.

Problem

The atelier needed a website to showcase its work, provide information about its services, and allow potential clients to get in touch. The website should reflect the atelier's brand and aesthetic, while also being functional and easy to navigate.

My contribution

Developed the main page, including navigation, an introduction to the atelier, service sections, the creation process, testimonials, and a contact form.

Technical approach

The website is built with Next.js and React. Tailwind CSS is used for the responsive layout, while separate components organize the navigation and contact form.

Catalog pagination is handled in the frontend, showing six search results per page. Search starts empty and runs when the user submits a query.

Result

The website provides a clear and elegant presentation of Agulha D'ouro Atelier's services and work. It allows potential clients to learn about the atelier, view its offerings, and easily get in touch.
