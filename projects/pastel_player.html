Entertainment / Web

Overview

A Spotify desktop player for Windows, built with Electron, React, and TypeScript, featuring a custom pastel interface and integrated music playback.

Context

A personal project combining desktop application development, interface design, and integration with Spotify’s authentication and playback services.

Problem

Create a desktop listening experience that plays music within the application without requiring the official Spotify Desktop app to remain open.

My contribution

I developed the responsive interface, integrated Spotify authentication and playlist loading, implemented playback controls, and configured secure communication between Electron and React. I also added automated tests and a Windows desktop shortcut

Technical Approach

  • Built reusable React components with TypeScript.
  • Used OAuth 2.0 with PKCE and encrypted storage for refresh tokens.
  • Integrated the Spotify Web API and Web Playback SDK.
  • Secured Electron with context isolation, sandboxing, and validated IPC methods.
  • Used a Widevine-enabled Electron runtime for protected audio playback.

Challenges

Handling DRM requirements and VMP signing, keeping playback controls synchronized with Spotify, and correctly processing API responses that contained empty bodies or plain text instead of JSON.

Result

Delivered a working desktop player with automatic playlist loading, album artwork, playback navigation, seeking, volume, shuffle, and repeat controls. Added loading and error states, responsive layouts, and 39 passing automated tests.

What I learned

I learned how to connect frontend behaviour with backend security, protect passwords using salted hashes, and manage sessions through HTTP-only cookies. I also developed practical experience with accessible interfaces, asynchronous requests, isolated testing, GitLab CI and Docker deployment. Troubleshooting the server taught me that rebuilding containers does not automatically update database schemas or stored credentials.
